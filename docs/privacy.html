Privacy Policy — Where's the remote?

Last updated: 12 August 2026

"Where's the remote?" is a Chrome extension that reads job postings on LinkedIn and Indeed and shows whether a role is genuinely remote, hybrid, onsite, or requires travel, based on the posting's own description text rather than the platform's own label. This page explains what data the extension handles and why.

What data is read

While you browse supported LinkedIn and Indeed job pages, the extension reads the text of job postings visible on the page (title and description). It does not read any other page content, and it does not run on any site other than LinkedIn and Indeed.

What data is sent off your device

To classify a job posting, the extension sends that posting's description text to our backend — a Cloudflare Worker we operate — which forwards it to OpenAI's API to determine the classification. Only the description text needed to classify that one posting is sent. No LinkedIn/Indeed account details, browsing history, cookies, or other personal information are collected or transmitted.

The Worker is stateless: it does not log or store the description text or the classification result. It simply relays the request to OpenAI, validates the response, and returns it to the extension. OpenAI's API does not use data submitted via its API to train its models by default.

What's stored locally

Once a job posting has been classified, the result (category, a short reason, and, if relevant, how often office attendance is required) is cached on your device using Chrome's local storage (chrome.storage.local) for 14 days, keyed to that job listing. This avoids re-classifying the same listing every time you see it. This cache never leaves your device and is removed automatically after 14 days, or immediately if you uninstall the extension.

What we don't do

  • We don't sell, rent, or share your data with third parties for advertising or any purpose unrelated to showing you the classification.
  • We don't use the data for any purpose beyond providing the extension's single feature.
  • We don't track you across sites, build user profiles, or use analytics/ad SDKs in the extension.
  • We don't require or collect any account, email, or sign-in information.

Third parties involved

  • Cloudflare hosts the relay Worker that forwards requests to OpenAI. Requests pass through Cloudflare's standard infrastructure logging, subject to Cloudflare's privacy policy.
  • OpenAI processes the submitted job description text to return a classification, subject to OpenAI's privacy policy.
